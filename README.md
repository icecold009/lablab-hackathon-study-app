# IceCold Sprint

IceCold Sprint is a focused study-planning MVP for students preparing for an exam with limited time. It turns confidence, exam importance, and available study time into a short, prioritised sprint plan, then uses a five-question quiz to decide what should happen next.

The interface is intentionally practical: a student should be able to open it, make a few honest decisions about their topics, and leave with a plan they can start immediately.

## The workflow

1. Configure an exam or load the Biology sample sprint.
2. Add topics and rate confidence and importance.
3. Generate a time-bounded prioritised plan.
4. Take a five-question topic quiz.
5. Review the score, explanations, progress, and next recommendation.
6. Refresh to restore local progress or reset the sprint.

## Product boundaries

The current release is deterministic and local-first. Progress is stored in `localStorage`, quiz content comes from the checked-in sample data, and the plan is generated by transparent scoring rules. Future model assistance must remain optional and preserve this fallback so the core study flow never depends on an unavailable API.

## Run locally

You need Node.js and npm.

```powershell
npm.cmd install
npm.cmd run dev
```

Run the validation checkpoint before sharing the app:

```powershell
npm.cmd run check
npm.cmd run smoke
```

Create a production build and preview it with:

```powershell
npm.cmd run build
npm.cmd run preview
```

## Project structure

```text
src/pages/              Setup, study plan, quiz, and progress screens
src/components/         Shared layout and small UI primitives
src/utils/              Plan and quiz generation logic
src/data/                Deterministic sample sprint data
src/hooks/               Local persistence helpers
scripts/smoke.mjs        Lightweight workflow smoke check
```
